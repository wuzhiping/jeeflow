# Backlog · 想法与待办池

> **作用**: 收集所有"以后做"的想法, 避免它们散落在各处或被遗忘.
> **区别于 `roadmap/candidates/`**: candidates 是经过评估的候选, backlog 是未评估的原始想法.
> **区别于 weekly**: weekly 是当下周计划, backlog 是跨周/跨月的远期想法.

---

## Backlog 规则

1. **任何想法** 都可入 backlog (产品/流程/文档/客户/技术)
2. **入 backlog 必须填**: 一句话 + 触发原因 + 估计影响
3. **每月初** 评估: 转 candidates / 拒绝 / 继续留
4. **拒绝必须说明理由**
