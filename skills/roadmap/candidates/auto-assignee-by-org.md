# 候选改进: 按组织架构自动选审批人

> **来源**: FB-0006 (客户 C-006 中型HR集成)
> **优先级**: 待评估
> **影响**: L2 流程客户 (中大型企业)

---

## 1. 客户原话

> 我们公司有 500+ 员工, 流程设计时希望:
> - '申请人所在部门的总监' 自动作为审批人
> - '申请人上两级领导' 自动作为审批人
> - '申请人 HRBP' 自动作为审批人
>
> 当前每个流程都要硬编码 assignee, 改一次组织架构所有流程都要改.

---

## 2. 已有方案 (FB-0006 已答复)

- jeeflow 支持 assignmentHandler 自定义 (docs/flow.md §6)
- 7 个内置 handler 可直接使用或扩展
- 客户可实现 SPI OrgUserProvider.get_dept_leader(userId, levels)

**问题**: 文档存在, 但缺**示例代码**, 客户上手成本高.

---

## 4. 优先级评估

| 维度 | 评估 |
|------|------|
| 客户影响面 | 中 (中型企业集成方) |
| 当前痛点 | 中 (硬编码维护成本) |
| 实现成本 | 低 (文档 + 示例) |
| 引擎风险 | 低 (不破坏兼容) |
| 紧急程度 | 低 (已答复, 客户自行实现) |

**建议**: Phase 9.2 优先做 3.1 (文档层), 3.2/3.3 看后续反馈.

---

## 5. 风险

- 多个客户可能要求不同组织模型 (扁平 / 矩阵 / 跨部门)
- 组织数据来源多样 (HR 系统 / OA / 飞书)
- 缓存策略 (组织数据查询性能)
