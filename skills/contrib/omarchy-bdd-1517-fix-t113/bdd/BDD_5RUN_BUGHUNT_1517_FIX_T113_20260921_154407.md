## 1. Bug Found — BUG-3 (decision expr 引用未声明变量)

### 1.1 现象

| 检查项 | 期望 | 实际 |
|--------|------|------|
| 启动 `f_days=5` | decision1 路由到 manager (`days > 3`) | decision1 路由到 **end1** (默认边) |
| manager 节点创建 | task DOING 出现 | ❌ 永远不创建 |
| 流程 path | apply → leader → **manager** → end | apply → leader → **end1** |
| 流程 state | **20** DONE | **20** DONE (看起来"成功"但走了错的路径) |
| approvalRecord | apply / leader / manager 三条 | apply / leader 两条 (manager 缺失) |

**根因**:
- 流程 JSON 的 decision 出边 `e3` 表达式写的是 `days > 3`
- 实际启动 variables 注入的 key 是 `f_days=5`
- `SimpleExprEvaluator._eval_node(ast.Name("days"), vars)` 执行 `vars["days"]` → KeyError → 抛 TypeError → 被 `except (TypeError, ValueError, KeyError, AttributeError)` 吞掉 → 返回 False
- engine.py:670-693 兜底走第一条无 expr 边 (e4 → end1)
- manager 节点从未被遍历到 (符合 FIX-T112 清理逻辑: e3 评估失败, e4 默认边未触发 orphan 清理)

### 3.2 Help 文案

W_DECISION_EXPR_UNKNOWN_VAR: "decision 出边 expr 引用了 variables 字典中没有的字段
                             (引擎会静默走到默认边, BUG-3 §116 BDD-1517 2026-09-21)",

### 3.3 检测实现

```python
import re as _re_expr
_PY_KW = {"True", "False", "None", "and", "or", "not", "in", "is"}
_re_ident = _re_expr.compile(r"[A-Za-z_][A-Za-z0-9_]*")
var_keys = set((variables or {}).keys())
for nid, n in node_by_id.items():
    if n.get("type") != TYPE_DECISION:
        continue
    unknown_seen = set()
    for eid in out_edges.get(nid, []):
        e = next((e for e in edges if e.get("id") == eid), None)
        if not e: continue
        expr = (e.get("properties") or {}).get("expr", "")
        if not expr: continue
        ids = set(_re_ident.findall(expr))
        ids = ids - _PY_KW
        ids = ids - var_keys
        for tok in ids:
            if len(tok) >= 2:
                unknown_seen.add(tok)
    if unknown_seen:
        warnings.append(VerifyIssue(
            W_DECISION_EXPR_UNKNOWN_VAR, "warning",
            f"decision 节点[{nid}] 的 expr 引用了未在 variables 中声明的字段: {sorted(unknown_seen)}。"
            f"引擎会因变量查找失败而走到默认边, 致该分支下游节点永远不创建。"
            f"建议: 1) 启动 variables 时加上这些 key, 或 2) 修改 expr 与 variables key 对齐。",
            node_ids=[nid],
            edge_ids=[e.get("id") for e in edges if e.get("sourceNodeId") == nid]
        ))
```
