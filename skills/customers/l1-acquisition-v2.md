---

## 1. 4 类 L1 客户画像回顾

| 类型 | 典型 | 触达难度 | 转化率预期 | 与 jeeflow 契合度 |
|------|------|----------|------------|--------------------|
| **A 中型 SaaS 集成方** | 想加审批流能力 | 中 (公开渠道) | 10% | 中 (需求间接) |
| **B 企业内部 IT / 数字化** | 统一审批流 | 高 (CIO 圈子) | 5% | 中 (合规重) |
| **C 工作流产品公司** | 寻找替代 Camunda/Flowable | 低 (BPM 社区) | 20% | **高 (需求直接)** |
| **D 教育 / 培训用户** | 教工作流原理 | 低 | 30% | 低 (非生产用户) |

---

## 2. 决策: 选 **类型 C (工作流产品公司)**

### 2.1 理由

1. **契合度最高**: jeeflow 是工作流引擎, C 类客户需求与产品功能**直接对齐**
2. **触达难度最低**: BPM 社区活跃 (Camunda Forum, Flowable Users, jBPM 社区)
3. **转化率最高**: 20%, 因为需求直接 (找替代品)
4. **价值最高**: 一旦集成, 单客户用量大 (生产环境)
5. **反馈质量高**: 工作流产品公司懂技术, 反馈专业 (如 flowuser 模式)

### 2.2 不选其他的原因

- **A**: 需求间接 (SaaS 是产品, 工作流是依赖), 转化慢
- **B**: CIO 圈子触达慢, 决策链长 (合规要求)
- **D**: 教育用户非生产用户, 反馈价值低

## 3. 软接触计划 (Step 2-7)

### Step 2 · 渠道铺设 (本周 W40 Thu-Fri)

**目标**: 加入 1 个 BPM 社区, 观察 3 天, 不立即互动.

**渠道候选**:
| 渠道 | 平台 | 触达方式 | 时间投入 |
|------|------|----------|----------|
| Camunda Forum | forum.camunda.io | 注册账号, 浏览"alternatives"话题 | 低 (1h 一次性) |
| Flowable Users | flowable.com/community | GitHub Discussions | 中 (持续) |
| jBPM 社区 | jbpm.org | Slack/Forum | 中 |
| Reddit r/workflow | reddit.com | 订阅 / 评论 | 低 |

**决定**: 先 **Camunda Forum** + **Flowable GitHub Discussions**, 观察 3 天.

### Step 3 · 软接触 (Week 41)

**目标**: 回答问题, 分享经验, 不推销.

**行动**:
- 每天浏览 15 分钟 BPM 社区
- 看到工作流相关问题 → 回答 (从 jeeflow 实战角度)
- 看到 "alternatives to Camunda" 话题 → 自然分享 (不直接推销)

### Step 4 · 识别信号 (Week 42)

**目标**: 寻找强信号客户 (如 flowuser 模式).

**强信号**:
- 对方主动问"jeeflow 怎么集成"
- 对方在 Camunda/Flowable 群问替代品
- 对方有具体业务场景 (中小型企业, 100-1000 员工)

### Step 5 · 首次对话 (Week 43)

**目标**: 1 次深入对话.

**提供**:
- 1 页产品介绍
- 5 分钟集成 demo
- OpenAPI 链接
- 公开 BDD 演示

### Step 6 · POC (Week 44)

**目标**: 1 个 sandbox POC.

**行动**:
- 给对方 sandbox 环境 (memory backend)
- 协助跑通 1 个真实流程
- 收集反馈 (走 FB 闭环)

### Step 7 · 转 L1 客户 (Week 45+)

**目标**: 1 个 L1 客户档案.

**行动**:
- 对方决定集成 → 创建 C-NNN.yaml (L1)
- 持续跟踪 → 进 RACI 矩阵
- 形成参考案例

## 4. 衡量指标 (90 天)

| 指标 | 目标 |
|------|------|
| 加入 BPM 社区数 | ≥ 2 |
| 回答问题数 | ≥ 5 (质量优先) |
| 强信号识别 | ≥ 1 |
| 首次对话 | ≥ 1 |
| POC 完成 | ≥ 1 |
| L1 客户档案 | ≥ 1 (Month 3 末) |

---

## 5. 风险

| 风险 | 缓解 |
|------|------|
| 社区反感推销 | 仅回答问题, 不主动推销 (Step 3) |
| 假装客户提问 | 一旦被发现, 信任崩塌 · 严格禁止 |
| 触达时间不足 | 每天 15 分钟, 持续 (低投入) |
| 转化率低 | 90 天目标 ≥ 1, 不强求 |
