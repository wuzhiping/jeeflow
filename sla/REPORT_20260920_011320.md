### Fix #1: §6.1.1 task 节点 pre_handle 触发 (FIX-T94 post-fix)

**问题**: bdd-1302 "pre_handle 被调用" 期望在 task 节点进入时触发, 但原 _execute_node 设计只对 custom/call_activity/decision/fork/sub-process 触发.

**根因**: 注释 "任务创建 ≠ 节点执行完成" 解释了为何不触发, 但 bdd-1302 设计预期 task 节点也触发.

**修复**: vendor/jeeflow/engine.py _execute_node 开头对 TYPE_TASK 分支也调 _fire_pre:
```python
if node.type == TYPE_TASK:
    self._last_created_record_done = False
    if not await self._fire_pre(node, inst): return  # ← 新增
    await self._create_task(node, inst, operator, vars_)
```

**验证**: bdd-1301-1305 现在 5/5 PASS (之前 4/5 FAIL #1302).
