# BDD #144 流程 ABANDON 清理 (20260919 175000)

## 测试场景
- 部署一个含 `assignmentHandler` 不存在 handler 的 task 节点的流程
- startAndExecute 触发 → auto-complete apply task → 走到 broken 节点 → handler 未注册 ValueError
- 期望：instance.state=99 ABANDON + 所有 DOING 任务 state=99 ABANDONED

## 测试结果（修复前）

| 字段 | 期望 | 实测（修复前） | 结论 |
|------|------|---------------|------|
| inst.state | 99 ABANDON | 99 ABANDON | ✓ |
| apply task state | 99 ABANDONED | 10 DOING | ❌ **孤立 todo** |

## 🐛 BUG 发现 + 修复

### Bug: ABANDON 路径不废弃 DOING 任务
- 引擎捕获下游 task 创建失败 → set inst.state=99 → update_instance
- 但 inst.tasks 中所有 DOING 任务**没被废弃**
- 结果：用户在 todoList 中看到 apply 任务，但 instance.state=99，困惑

### 修复（FIX-T44 2026-09-19）
- `vendor/jeeflow/facade.py:_startAndExecute:202-225`（execute_process_task 失败路径）
- `vendor/jeeflow/engine.py:start_process_instance_by_id:91-117`（_execute_node 失败路径）
- 两个路径都加：遍历 inst.tasks → 状态=DOING 的改 ABANDONED → update_instance + 逐个 update_task

### 调试历程（弯路）
- 第一次修复只在 engine.start_process_instance_by_id 加 FIX-T44
- 测试发现 apply task 仍 state=10
- 多次怀疑：vendor 加载、Python 版本、pycache 等
- **真正原因**：startAndExecute 不只走 start_process_instance_by_id，**还在 facade._startAndExecute:199 调 execute_process_task**（auto-complete apply）
- execute_process_task 推进 apply→broken → ValueError，facade 重新捕获
- **必须两个入口都修**

## 测试结果（修复后）

|------|------|------|
| inst.state | 99 ABANDON | ✓ |
| apply task state | **99 ABANDONED** | ✓ |
