## 3. 关键发现

1. **同设计可多次部署**：每次 deploy 创建新 processDefineId（递增 ID）
2. **版本自动递增**：v0 → v1 → v2
3. **实例绑定版本**：启动时用哪个 pdid → 实例 processDefineId = 那个 pdid
4. **版本间隔离**：V1 和 V3 实例流程定义独立，互不影响
5. **deploy API 行为**：POST /wf/processDesign/deploy 接受 designId，每次创建新 define
