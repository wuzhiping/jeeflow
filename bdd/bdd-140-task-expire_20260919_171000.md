# BDD #140 任务过期 expireTime 边界 (20260919 171000)

## 测试目标
- 验证 Python 引擎是否处理 task.expireTime
- 验证过期任务是否被自动处理（跳过/拒绝/提醒）

## 测试结果

| 项 | 期望 | 实测 | 结论 |
|---|------|------|------|
| task.expireTime | 2020-01-01 | None | ❌ **未设置** |
| 实例 state | 10 DOING (待办 apply) | 20 DONE | ⚠️ startAndExecute 自动完成 |
| 任务 state | 10 DOING | 20 DONE | ⚠️ 同上 |
| activeTaskList | [apply] | [] | ⚠️ 同上 |

## 🐛 限制发现：Python 引擎**未实现**任务过期

### 现象
- `ProcessTask.expireTime` 字段在 model 中存在（`vendor/jeeflow/model.py:119`）
- 流程定义中节点 `properties.expireTime` 字段可设置（如 `"2020-01-01 00:00:00"`）
- 但 `_create_task()` 完全不读 `node.properties.expireTime`，落库时 `expireTime=None`
- 无任何后台定时任务扫描过期 task
- 无自动跳过/拒绝/邮件/站内信机制

### 引擎代码（`vendor/jeeflow/engine.py:_create_task`）
```python
nt = inst.create_task(self._next_id(), node.id, ..., perform_type, task_type)
# 不读 node.properties.expireTime
# 无 setattr(nt, "expireTime", ...)
```

### 已知限制（新增 §68）
- **§68 任务过期 expireTime 未实现**
  - 字段在 model 存在（`ProcessTask.expireTime`）以兼容 Java
  - 节点 `properties.expireTime` 不被读取
  - 无定时任务扫描过期
  - 无自动处理（跳过/拒绝/提醒）
  - **业务方需自行实现**：用 custom 节点 + 定时器对比当前时间 vs expireTime

## 兼容 Java 端
- 字段 `expireTime` 保留在 API 响应（`facade.py:1318,1579,1591,1612`）
- 都是 None（Python 端不设置）
- Java 端设置的值在 PG/MySQL 数据库里能读出

## 结果
- memory (8101): ⚠️ 限制确认
- pg (8102): ⏭️ 暂未跑
