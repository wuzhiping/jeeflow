# BDD Task 23: 5 人 PARALLEL 会签 + ONE_VOTE_VETO（PASS）

- **时间**：2026-09-17 14:00:00（TS=20260917140000）
- **JSON 定义**：
  - `./bdd/bdd-sign-parallel-5_20260917140000.json`（Case A: ALL）
  - `./bdd/bdd-sign-parallel-5-veto_20260917140000.json`（Case B: ONE_VOTE_VETO）
- **服务**：main.py（内存后端）

## 1. 场景设计

### Case A — 全员通过（PARALLEL ALL）

| 节点 | 类型 | 配置 |
|---|---|---|
| committee | task | 5 actor (leader/manager/director/boss/userA), performType=1, countersignType=PARALLEL, countersignCompletionCondition=ALL |

### Case B — 一票否决（PARALLEL ONE_VOTE_VETO）

同上但 countersignCompletionCondition=**ONE_VOTE_VETO**。

## 2. 测试结果

### Case A — 5 人依次 agree

```
state=10 active=5  (5 个 committee 并行 ACTIVE)
leader agree → manager agree → director agree → boss agree → userA agree
state=10 active=1  (notify ACTIVE)
notify agree → state=20 ✅
```

历史：`['apply', 'committee', 'notify', 'decision_pass', 'end']`

### Case B — leader 一票 reject

```
state=10 active=5  (5 个 committee 并行 ACTIVE)
leader submitType=20 (reject)
→ state=10 active=0，剩余 4 个 committee 自动 ABANDON (state=99)
→ 直接 end（decision 走默认边）
state=20 ✅
```

历史：`['apply', 'committee', 'decision_pass', 'end']`

## 3. 关键发现

1. **countersignCompletionCondition=ALL**：5 个 committee task 全部 DONE 才流转（实际是 PARALLEL 默认行为）
2. **countersignCompletionCondition=ONE_VOTE_VETO**：任一 task DONE 即流转，剩余 ABANDON（state=99）
3. **submitType=20 (REJECT) 一票否决**：PARALLEL 一票拒绝比 ALL 提前结束流程
4. **state=99 ABANDON**：未被执行的会签 task 状态
