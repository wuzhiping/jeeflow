1. **FQCN 正确格式**：`com.mldong.jeeflow.interceptor.impl.OrgUserAssignmentHandlers$TaskRoleAssigneeHandler`（注意 `$` 不是 `.`）

6. **AGENTS.md §3.3 已修正**：节点 id 可用作 role_code（与 SPI role 对应）

## 5. Engine 实现（engine.py L415-444）

```python
assignee = node.properties.get("assignee", "")
if assignee:
    actors = []
    for a in assignee.split(","):  # 字面量逗号分割
        if "applicant" in a:
            a = a.replace("applicant", inst.operator)
        if a in vars_:
            val = vars_[a]
            if isinstance(val, (list, tuple)): actors.extend(...)
            else: actors.append(str(val))
        else:
            actors.append(a)
    return actors
handler_name = node.properties.get("assignmentHandler", "")
if handler_name and self.ext and self.ext.registry:
    handler = self.ext.registry.find_assignment(handler_name)
    if handler:
        return await handler.assign(node, inst, operator)
```

当 handler 不存在 → 回到默认（fallback 到 assignee 字面量）。
当 handler 存在 → handler.assign(node, inst, operator) 返回 list。
