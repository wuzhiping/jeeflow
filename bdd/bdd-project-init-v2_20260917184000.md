# BDD Task 1: 项目立项审批 V2（bdd-project-init-v2_20260917184000）

## 流程设计
- 提交立项 (apply, applicant=user1)
- 部门领导审批 (dept_approve, assignee=leader)
- 金额决策 (amount_decision, decision(f_amount<=500000))
- 经理审批 (manager_approve) OR 总经理审批 (boss_approve)
- 财务会签 (finance_sign, assignmentHandler=TaskRoleAssigneeHandler, PARALLEL)
- 结束 (end)

## SPI 角色
- `finance_sign` = ['leader', 'manager']（财务会签参与人）
- `pm_review` = ['leader']（备用）
- `to_dept_approve` = ['leader']
- `apply` = ['user1']
- `task1` = ['leader']

## 测试场景
1. 用户 user1 提交立项（30万）
2. leader 完成 dept_approve
3. manager 完成 manager_approve（30万 ≤ 50万）
4. leader 完成 finance_sign task 1
5. manager 完成 finance_sign task 2
6. 流程结束

## 测试结果（双端 PASS）
- memory (8101): leader→manager→leader→manager ✅ state=20
- pg (8102): leader→manager→leader→manager ✅ state=20
