# BDD #136 字典 wf_* 路由 + decision 集成 (20260919 163000)

## 流程设计
```mermaid
flowchart LR
    start([开始]) --> apply[请假申请 user1<br/>f_leave_type=字典值]
    apply --> dec{类型}
    dec -->|annual/personal| hr_a[HR审批 director]
    dec -->|sick| mgr_a[经理审批 manager]
    dec -->|其他| boss_a[老板审批 boss]
    hr_a --> end([结束])
    mgr_a --> end
    boss_a --> end
```

## 场景
- decision expr 引用表单字段 `f_leave_type`，值是字典 wf_leave_type 的 value
- annual/personal → HR，sick → 经理，其他 → 老板
- `/api/dicts` 返回字典表

| 2 | sick | mgr_a | mgr_a | ✅ |
