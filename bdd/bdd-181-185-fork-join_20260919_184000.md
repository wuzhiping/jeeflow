## BDD #184 限制（重复 end finish）

**现象**：fork 出的两条路径都各自连接到 end，无 join
- leader 办完 → 走 end → inst.finish() → state=20
- manager 办完 → 走 end → inst.finish() 再触发一次 → state=20 (幂等)
- 第一次 finish 把 instance 设为 DONE，第二次 finish 重复执行

**影响**：
- 功能上正确（最终 state=20）
- 但 processFinish 事件触发 2 次（双 PROCESS_FINISH 事件）
- 不优雅但 idempotent

**绕过方法**：使用 join 节点避免重复触发
**建议**：end 节点增加幂等检查（state==DONE 时直接 return）
