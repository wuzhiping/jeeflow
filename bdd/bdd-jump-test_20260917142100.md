## 3. 关键发现

1. **submitType=4 JUMP**：用 `taskName` 参数指定目标节点
2. **JUMP 语义**：当前 task DONE → 直接跳到指定节点（跳过中间）
3. **facade.py:308**：JUMP → `engine.execute_and_jump_task(task_id, operator, args, taskName)`
4. **JUMP 后的 task**：正常创建 + 处理
5. **JUMP 不校验边**：可以跳到任意节点（即使没有直接边连接）
