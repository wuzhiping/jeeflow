# BDD #142 委派 delegate 跨 instance 状态 (20260919 173000)

## 测试目标
- 验证 Python 引擎是否支持 `delegate`（将当前任务临时委派给另一用户处理）
- 验证委派后受托人能否看到该 instance 的 todo
- 委派完成后原 actor 是否仍可见

## 结论：Python 引擎**未实现**委派 delegate

**支持的（surrogate）**：
- 全局授权规则：用户A 可设置"我不在时所有任务给用户B"
- 端点：`/wf/processSurrogate/save` `/page` `/update` `/delete`
- 适用场景：长期代理（如请假、出差）
- BDD #137 已测

**不支持的（delegate）**：
- 临时将**当前 instance**的当前 task 委派给另一用户
- 委派完成后原 actor 收回（surrogate 是持续生效）
- 跨 instance 状态切换（per-task scope vs global scope）

## API 端点对比

| 引擎 | 端点 | 语义 |
|------|------|------|
| Java | `processTask/delegate` | 委派当前 task 给其他用户 |
| Python | **未实现** | surrogate 只能全局规则 |

## 业务方临时方案
1. 用 surrogate 规则（全局，但需事后撤销）
2. 用 addCandidate 临时增加处理人（不撤回原 actor）
3. 在 custom 节点编程实现 delegate 业务（call addCandidate + removeActor）

## 已知限制（新增 §69）
- **§69 任务委派 delegate 未实现**
  - 仅支持 surrogate（全局授权）
  - 不支持 per-instance / per-task 临时委派
  - 业务方用 surrogate 临时规则 + 主动撤销代替
