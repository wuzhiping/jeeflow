## BUG 描述

`SimpleExprEvaluator` v1.9.0 不支持 `ast.Attribute`（点访问）和 `ast.Subscript`（下标）。
- 决策 expr `#f_meta.level >= 3` 抛错被捕获 → False → 走兜底边
- 决策 expr `#f_tags[0] == 'urgent'` 同上

**根因**：`main_common.py:170` 注释说"不支持的节点类型（函数调用/属性/下标）→ 兜底 False"，
但属性和下标是常规数据访问需求，应支持。

## 修复 (FIX-T52 2026-09-19 §100)

`main_common.py:_eval_node` 末尾增加：

```python
if isinstance(node, ast.Attribute):
    value = self._eval_node(node.value, vars)
    if value is None:
        return None
    try:
        return value[node.attr]
    except (KeyError, TypeError, IndexError):
        return None
if isinstance(node, ast.Subscript):
    value = self._eval_node(node.value, vars)
    if value is None:
        return None
    key = self._eval_node(node.slice, vars)
    if key is None:
        return None
    try:
        return value[key]
    except (KeyError, TypeError, IndexError):
        return None
```

**安全考量**：
- 拒绝属性名以 `_` 开头（防 dunder 访问）—— 当前实现无此限制，
  实际风险低（无 `__import__` 等函数调用能力）
- 仍禁止函数调用（`ast.Call`）
- 仅 dict/list/str 的 [] 索引和 .attr 访问
