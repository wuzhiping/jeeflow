# BDD #133 JUMP 跳转到中间节点 (20260919 160000)

## 流程设计
```mermaid
flowchart LR
    start([开始]) --> apply[申请]
    apply --> step1[步骤1 leader]
    step1 --> step2[步骤2 manager]
    step2 --> step3[步骤3 director]
    step3 --> end([结束])
```

## 场景
- step1 完成后用 `submitType=4` (JUMP) + `taskName=step3` 跳到 step3
- step2 应当被跳过
- step3 完成后流程正常到 end

## 测试结果

| 用例 | 期望 | 实测 | 结论 |
|------|------|------|------|
| step1 JUMP 跳到 step3 | step2 跳过 | step2 没出现在 tasks | ✅ |
| step3 仍可执行 | director 处理 | director todoList 可见 | ✅ |
| step3 → end | state=20 | state=20 | ✅ |
| JUMP 路径无残留 step2 task | 无 | 无 | ✅ |

## JUMP 行为
- `submitType=4` (JUMP) + `taskName=XXX` 跳到指定 task
- 中间节点 task 不创建
- 跳过的 task 不出现在 approvalRecord（已验证 step2 没出现）
