## 🐛 BUG 发现 + 修复（FIX-T42 2026-09-19）

### Bug: `processDesign/save` 不按 name UPSERT

**位置**：`vendor/jeeflow/facade.py:_processDesign_save:465-500`

**代码（修复前）**：
```python
async def _processDesign_save(self, args: dict) -> dict:
    ...
    design_id = self._to_int(args.get("id"))
    if not design_id:
        # 总是创建新 design，没有按 name 查重
        design = ProcessDesign(name=str(args.get("name", "")), ...)
        await ext.save_design(design)
    else:
        # 仅当 id 明确给出时才更新
        ...
```

**现象**：连续 2 次 `processDesign/save`（相同 name，无 id）→ 创建 2 个不同 designId，processDesignHis 分散记录。

### 修复（FIX-T42 2026-09-19）

1. **`vendor/jeeflow/repository/ext.py:find_design_by_name`** - 新增端点
   ```python
   async def find_design_by_name(self, name: str) -> Optional[ProcessDesign]:
       if not name: return None
       async with self._conn() as conn:
           row = await conn.fetchone(
               self._sql(f"SELECT {self._DESIGN_COLS} FROM wf_process_design WHERE name = ? ORDER BY id DESC LIMIT 1"),
               (name,))
       if not row: return None
       return self._map_design(row)
   ```

2. **`vendor/jeeflow/memory.py:find_design_by_name`** - 内存端点
   ```python
   async def find_design_by_name(self, name):
       if not name: return None
       candidates = [d for d in self._designs.values() if d.name == name]
       if not candidates: return None
       return max(candidates, key=lambda d: d.id or 0)
   ```

3. **`vendor/jeeflow/facade.py:_processDesign_save`** - 走 UPSERT
   ```python
   if not design_id:
       name = str(args.get("name", ""))
       existing = None
       if name and hasattr(ext, "find_design_by_name"):
           existing = await ext.find_design_by_name(name)
       if existing is not None:
           design = existing  # 复用 id
           # 走更新路径
       else:
           design = ProcessDesign(name=name, ...)
           await ext.save_design(design)
   ```
