## 2. 修复过程问题 & 解决

### 问题 1: SPI 函数 mutable default 警告

```python
# ❌ 错误：token={} 是 mutable default
def SPI(payload, token={}):
    return token["map"].get(dept_id, [])
# TypeError: 'map' — token 已被共享修改
```

**解决**：把 map 移到模块级常量，函数内只读：

```python
DEPT_LEADER_MAP = {"D01": ["leader"], ...}
def SPI(payload, token={}):
    return DEPT_LEADER_MAP.get(dept_id, ["leader"])
```

### 问题 2: SPI 函数签名不匹配

```python
# ❌ 错误：SPI(payload) 单参数
def SPI(payload) -> list: ...
# TypeError: pocketflow() takes 1 positional argument but 2 were given
```

**解决**：必须接受 (payload, token) 双参数：

```python
def SPI(payload, token={}) -> list: ...
def pocketflow(payload, token={}) -> list: return SPI(payload, token)
```
