# BDD #137 surrogate 委托 self 边界 (20260919 164000)

## 流程设计
```mermaid
flowchart LR
    start([开始]) --> apply[申请 user1]
    apply --> leader_review[主管 leader]
```

## 场景
- 委托 user1 → user2（正常委托）
- 委托 user1 → user1（**self-surrogate 边界**）
- 受委托人 todoList 是否能看到原任务

## 测试结果

| 用例 | 期望 | 实测 | 结论 |
|------|------|------|------|
| surrogate save (user1→user2) | 成功 | 成功 | ✅ |
| surrogate save (user1→user1 self) | 成功 | 成功 | ✅ |
| 委托列表查 user1 | 2 条 | 2 条 | ✅ |
| user2 todoList（受委托） | 应看到 user1 任务 | count=0 | ⚠️ §40 已知 |

## 观察

- self-surrogate 允许保存（不强制 operator != surrogate）
- 受委托人 todoList 不自动展开（§40 已知）
- 需手动调 `processTask/surrogate` addCandidate 才能在 todoList 看到

## 设计判断
- self-surrogate 在大多数场景下无意义（user1 委托给 user1）
- 但允许保存（不报错），兼容性更好
- 建议增加：保存时校验 operator != surrogate，否则 warning

## 结果
- memory (8101): ⚠️ 部分 PASS（surrogate 保存 OK，但自动展开 todoList 已知 §40）
- pg (8102): ⏭️ 暂未跑
