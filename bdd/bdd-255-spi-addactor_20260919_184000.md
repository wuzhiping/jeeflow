# BDD #255 SPI role + 加签 + 减签 (20260919 184000)

## 测试场景
- 任务节点 `audit` 用 `TaskRoleAssigneeHandler` + `roleCode=audit_team`
- `audit_team` 包含 userA, userB, userC（已在 SPI demo）
- 启动后 userA/userB/userC 都收到 todo
- 加签 director
- 减签 userB
- userA 办完 → 应推进到 end

## 测试结果

| 步骤 | 实测 | 状态 |
|------|------|------|
| 启动 audit (role=audit_team) | userA, userB, userC 各 1 todo | ✅ |
| addCandidate director | director 收到 todo | ✅ |
| removeCandidate userB | userB todo 消失 | ✅ |
| userA 办完 (submitType=0) | state=20 DONE | ✅ |

## 结论
