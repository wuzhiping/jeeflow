## 🐛 文档/测试 BUG #173: JUMP 字段名

**现象**：调用方传 `targetTaskName` 时被忽略，走了 ROLLBACK 默认路径
**正确字段**：`taskName`（不是 `targetTaskName`）
**位置**：`vendor/jeeflow/facade.py:374`

```python
# 修复前认知（错误）
exec_t(tid, op, 4, {"targetTaskName": "step3"})

# 正确
exec_t(tid, op, 4, {"taskName": "step3"})
```

**修复建议**：在 facade._processTask_execute 兼容两个字段名
```python
target_name = str(args.get("taskName") or args.get("targetTaskName") or "")
```

**关联 BUG #146 (FIX-T45)**：同类问题（字段不识别）
**建议 FIX-T49**：JUMP 字段 fallback
