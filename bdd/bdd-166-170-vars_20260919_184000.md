## BUG #170 设计限制

**位置**：`main_common.py:SimpleExprEvaluator` 白名单
- ❌ 属性访问 (`data.amount`)
- ❌ 下标 (`data['amount']`)
- ❌ 函数调用

**示例**：
```python
# 错误（不会工作）
expr: "data.amount>=100"  # 属性访问 → 拒
expr: "data['amount']>=100"  # 下标 → 拒

# 正确
expr: "amount>=100"  # 顶层 key 直接用
```

**绕过方法**：
- flatten 嵌套：把 `data.amount` 拆成 `data_amount` 顶层 key
- 用 `f_amount` (f_ 前缀) 启动时传值

**影响**：业务方传 `data: {amount: 150}` 后，decision expr 无法直接引用，需先做 flatten
**建议**：设计器自动 flatten 或扩展 `SimpleExprEvaluator` 支持 subscript
