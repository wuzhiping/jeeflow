## §70 历史

BDD #192-#195 确认以下 4 个 endpoint 缺失：
- `processInstance/suspend` - 实例挂起
- `processTask/transfer` - 任务转交
- `processTask/comment` - 任务评论
- `processTask/extra` - 任务额外信息

## FIX-T53 实现（2026-09-19）

### 1. processInstance/suspend
- 校验 state ∈ {DOING=10, PENDING=50}
- 修改 inst.state = PENDING (50)
- 返回 `{id, state: 50}`

### 2. processInstance/resume
- 校验 state == PENDING (50)
- 修改 inst.state = DOING (10)
- 返回 `{id, state: 10}`

### 3. processTask/transfer
- 校验 task.taskState == DOING
- 修改 task.actorIds = [target, ...]（支持逗号分隔多 actor）
- 返回 `{taskId, oldActors, newActors}`

### 4. processTask/comment
- 追加到 task.variables["_comments"] 列表
- 每条评论: `{operator, comment, time}`

### 5. processTask/extra
- 合并到 task.variables["_extra"] dict
- 支持任意 key-value 字段
