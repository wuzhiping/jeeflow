# BDD #251 verify 规则系统 (最终版 20260919 181000)

## 目标
把所有 BDD 狩猎中累积的 BUG / 限制 / 反模式，沉淀到流程定义 save/update/deploy 入口的 verify 阶段，**防止错误流程进入运行**。提供 `skipVerify: true` 跳过开关供开发测试新功能或验证 BUG 时使用。

## 规则集（最终 11 + 8 + 4 = 23 条）

| E006 | 无 end 节点 | BDD #211 |

| ID | 规则 | 来源 |
|----|------|------|

### Patterns (P001-P004) - 反模式建议

| ID | 规则 |
|----|------|
| P001 | 会签只有 1 个 actor (退化为普通 task) |

| P004 | decision 嵌套深度 > 3 |

## 实现

### 1. 新增模块 `vendor/jeeflow/verify.py` (~270 行)
- `verify_flow(flow, variables) -> (errors, warnings, patterns)`
- `format_issues(issues) -> str`
- `VerifyIssue` 类（code, level, msg, node_ids, edge_ids）
- 经典 DFS 环检测（gray→gray = 环）
- 同步到 `.venv/lib/python3.12/site-packages/jeeflow/verify.py`

### 2. 接入 6 个入口
- `_processDesign_save` - save 设计
- `_processDesign_update` - update 设计基本信息
- `_processDesign_updateDefine` - 更新定义
- `_processDesign_redeploy` - 重新部署
- `_processDesign_deploy` - 通过 design deploy (透传 skipVerify)
- `_deploy` - 直接 deploy

### 3. 跳过开关
- 请求 body 含 `"skipVerify": true` 时**只 warn 不 raise**
- 用途：开发测试新功能 / 验证已知 BUG
- 同步到所有嵌套调用 (deploy 透传给 _deploy)

### 4. 公共预检端点 `/wf/verify`
- POST {content, variables?} 
- 返回 `{valid, errors, warnings, patterns, summary}`
- 不写设计, 仅预检
