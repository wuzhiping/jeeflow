# BDD #149 SPI 角色 + 字段权限 + 跨角色委托 (20260919 182000)

## 流程设计

```mermaid
flowchart TD
    start([开始]) --> apply[申请人<br/>applicant]
    apply --> dept_lead[部门负责人<br/>DeptLeaderAssignmentHandler]
    dept_lead --> hr[HR 审核<br/>TaskRoleAssigneeHandler<br/>role=hr]
    hr --> boss[总经理]
    boss --> end([结束])
```

## 关键设计点

- **applicant 关键字**：节点 assignee="applicant" → 运行时替换为 inst.operator
- **DeptLeaderAssignmentHandler**：根据发起人 u_deptId 查 DEMO_DEPT_LEADERS.json
- **TaskRoleAssigneeHandler**：根据 properties.roleCode 查 DEMO_ROLE_TO_USERS.json
- **4 个角色**：applicant → dept leader → hr → boss

## SPI 数据准备

新增 `spi/demo/DEMO_ROLE_TO_USERS.json`：
```json
{
  "hr": ["cashier"],
  "dept_lead": ["manager"]
}
```
