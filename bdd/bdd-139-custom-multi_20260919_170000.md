## 🐛 BUG 发现 + 修复

### Bug: custom 节点 handler 写入 vars_ 不传播到 inst.variables

**现象**：3 个 custom 节点跑完后，下游 task 节点的 `inst.variables` 仍无 ts1/ts2/computed。

**根因**：`engine.py:_execute_node` 只在 `end` 节点处把 vars_ 合并到 inst.variables
（`_merge_exec_into_instance`），custom 节点中间执行不合并，导致下游读不到 handler 写入的值。

**修复（FIX-T41 2026-09-19）**：
- `vendor/jeeflow/engine.py:_execute_custom_node` 在 handler 执行后立即合并：
  ```python
  inst.variables = _merge_exec_into_instance(inst.variables, vars_)
  await self.repo.update_instance(inst)
  ```
- 与 end 节点同款合并（`update_instance` 保证持久化）

## 新增 handler（BDD #139 验证）

`main_common.py:build_custom_handlers` 新增 2 个：
- `TimestampHandler`：返回当前时间 ISO 字符串
- `AppendVarsHandler`：从 args JSON 读 dict 合并到 vars_（不覆盖已有 key）
