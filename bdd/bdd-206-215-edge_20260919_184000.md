## 🐛 BUG #209 #213 FIX-T50（2026-09-19）

### Bug: deploy 不校验 cycle（环）
- 现象：自环 / 2 节点环会导致引擎死循环（无界创建 task）
- #209 自环：`loop→loop+end` → loop 任务完成后到 end 也到 loop → 反复创建
- #213 2 节点环：`a→b→a` → a 完到 b，b 完到 a，永远循环

### 修复
`vendor/jeeflow/facade.py:_deploy` 加 DFS 环检测：
```python
def _has_cycle(graph):
    WHITE, GRAY, BLACK = 0, 1, 2
    color = {n: WHITE for n in graph}
    def dfs(u):
        color[u] = GRAY
        for v in graph[u]:
            if color[v] == GRAY: return True
            if color[v] == WHITE and dfs(v): return True
        color[u] = BLACK
        return False
    for n in graph:
        if color[n] == WHITE and dfs(n):
            return True
    return False
```

deploy 时调 `_has_cycle(adj)` → 命中 raise `ValueError("流程含环（cycle）...")`
