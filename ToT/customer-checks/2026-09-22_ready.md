## ⚠️ 已知问题（不影响可用性）

### P1：引擎 dept 解析走 fallback

- **现象**：用户 `u_fdp_pm` 在 SPI 中 `deptId=DFDEP, deptName=默认部`（应是 "FDEP协作组"）
- **原因**：引擎的 dept lookup 路径未走 SPI 的 `_DictProxy`（vender/jeeflow/engine.py 自带的 dept 解析）
- **影响**：仅显示问题，**不阻塞**流程推进（userId 始终正确，SPI 解析到 u_fdp_pm）
- **修复方案**：v0.7+ 引入 assignmentHandler 时同步修复；或 vendor/jeeflow/engine.py 加 SPI 拦截

### 冒烟测试遗留

- 两个 instance 卡在 stage_intake / stage_pm（DOING 状态）
- **可选**：继续推进 / 提交驳回 / 标记为已完成 / 忽略
- **建议**：作为"系统工作正常"的证据保留，或手动 archive

## 复现脚本

```bash
TARGET="https://abc.feg.cn/jeeflow"

# 8 项检查一气呵成
echo "[1/8] healthz"
curl -sf -o /dev/null -w "  HTTP %{http_code}\n" --max-time 5 "$TARGET/healthz"

echo "[2/8] stats"
curl -sf -o /dev/null -w "  HTTP %{http_code}\n" --max-time 5 "$TARGET/api/stats"

echo "[3/8] users count"
curl -s -X POST "$TARGET/api/users" -H "Content-Type: application/json" \
    -d '{"pageNum":1,"pageSize":999}' --max-time 5 \
    | python3 -c "import sys,json; print(f'  count={len(json.load(sys.stdin)[\"data\"])}')"

echo "[4/8] roles fdep_*"
curl -s -X POST "$TARGET/api/roles" -H "Content-Type: application/json" \
    -d '{"pageNum":1,"pageSize":999}' --max-time 5 \
    | python3 -c "import sys,json; d=json.load(sys.stdin); fdep=[r for r in d['data'] if 'fdep' in str(r.get('roleId',''))]; print(f'  fdep_roles={len(fdep)}')"

echo "[5/8] fdep deployed"
curl -s -X POST "$TARGET/wf/processDefine/page" -H "Content-Type: application/json" \
    -d '{"pageNum":1,"pageSize":999}' --max-time 5 \
    | python3 -c "import sys,json; rows=json.load(sys.stdin)['data']['rows']; fdep=[r for r in rows if r.get('name')=='fdep']; print(f'  {\"✅ id=\"+str(fdep[0][\"id\"]) if fdep else \"❌\"}')"

echo "[6/8] doing"
curl -s -X POST "$TARGET/wf/processInstance/doingList" -H "Content-Type: application/json" \
    -d '{"limit":50}' --max-time 5 \
    | python3 -c "import sys,json; d=json.load(sys.stdin)['data']; print(f'  instances={d.get(\"instance_count\",0)}, tasks={d.get(\"task_count\",0)}, nodes={d.get(\"by_node\",{})}')"

echo "[7/8] smoke startAndExecute"
FDEP=$(curl -s -X POST "$TARGET/wf/processDefine/page" -H "Content-Type: application/json" \
    -d '{"pageNum":1,"pageSize":999}' --max-time 5 \
    | python3 -c "import sys,json; rows=json.load(sys.stdin)['data']['rows']; fdep=[r for r in rows if r.get('name')=='fdep']; print(fdep[0]['id'] if fdep else '')")
RESP=$(curl -s -X POST "$TARGET/wf/processDefine/startAndExecute" \
    -H "Content-Type: application/json" -d "{\"processDefineId\":\"$FDEP\",\"operator\":\"u_fdp_pm\"}" \
    --max-time 15)
echo "  $RESP" | head -1
INSTANCE=$(echo "$RESP" | python3 -c "import sys,json; print(json.load(sys.stdin).get('data',{}).get('processInstanceId',''))" 2>/dev/null)

echo "[8/8] smoke execute"
TODO=$(curl -s -X POST "$TARGET/wf/processTask/todoList" -H "Content-Type: application/json" \
    -d "{\"operator\":\"u_fdp_pm\",\"limit\":50}" --max-time 5 \
    | python3 -c "import sys,json; rows=json.load(sys.stdin)['data']['rows']; my=[t for t in rows if t.get('processInstanceId')=='$INSTANCE']; print(my[0]['id'] if my else '')")
if [ -n "$TODO" ]; then
  curl -s -X POST "$TARGET/wf/processTask/execute" \
    -H "Content-Type: application/json" \
    -d "{\"processTaskId\":\"$TODO\",\"operator\":\"u_fdp_pm\",\"submitType\":1}" \
    --max-time 15 -w "  HTTP %{http_code}\n" | tail -1
fi
```
