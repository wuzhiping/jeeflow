## 3. ADR

| 决策 | 选择 | 理由 |
|------|------|------|
| 单独建文档 vs 集成到 README | **单独**（GETTING_STARTED.md） | README 是工作规范；NEW 是导航入口，职责不同 |
| 文档命名 | `GETTING_STARTED.md`（UPPER_SNAKE） | 与 README/HANDBOOK 同级别；凸显"这是入口"|
| 入口放置 | ToT/ 根目录 | 与 README / HANDBOOK 同层；最高可发现性 |
| 路径设计 | 4 角色 4 路径（不是 5 条目） | 用户首先问"我是谁"，再问"做什么"|
| 内容深度 | 仅入口 + 速查，不重复深文档 | 深内容在 roadmap / HANDBOOK / SOP |
