## 4. 经验沉淀索引

详见各 Iter 文件的"经验沉淀"段。主题：
- **actor resolver**（#12）：3 种语法（@role / 顶级变量 / applicant）
- **decision mem**（#18）：comment/decision_reason/decision_memo 3 字段
- **驳回机制**（#11）：submitType=5 RE_APPLY 优于 submitType=2 REJECT
- **CI 阶段化**（#22）：dry-run + baseline-only + 实跑三阶段
- **dashboard 双格式**（#23）：JSON 机器 + HTML 人类
- **archive 闭环**（#28）：SPI 背景 + 报告 + 打包 + file-share + 清理
- **dry-run 通用化**（#29）：所有 destructive 操作前可预览
- **配置集中化**（#30）：每个外部端点都应有 §9.6 检查
- **AI 伙伴 + 角色建模**（#31）：flow-operator = 2-lens（initiator/assignee）+ 最小知情原则
- **渐进式推进**（#32）：A→C→D 顺序原则 + 容错 3 道防线 + 文档与实现对齐
- **Config 工具 + 写入前验证**（#33）：URL / user_id / fdep 三道防线 + role_lenses 强制默认 + get_context 是 AI 契约
- **Job Card endpoint**（#34）：engine 一致性 + 路径安全 + 静态读 + SKILL 同步 Work Guidance
- **text.value 极简**（#35）：原则 B（"任务说清楚就足够"）+ save vs deploy 双层解耦 + version 字段在 content 内 + git commit 需用户授权
