## 3. 关键发现

1. **vendor 集中兜底**：把"列类型差异"从 main_pg.py 抽到 vendor，让 SQLite/MySQL 也受益
2. **dataclass 默认值改 Any**：避免 type hint 与 PG BOOLEAN 冲突
3. **str() 兜底兼容**：PG VARCHAR 列强转 str，SQLite int 列也接受字符串（隐式转换）
4. **_parse_m_query 驼峰命名**：m_EQ_isDeployed 正确拆 column='t.is_deployed'，m_EQ_is_deployed 拆错
