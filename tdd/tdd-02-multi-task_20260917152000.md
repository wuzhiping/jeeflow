## 3. 关键发现（§69 经验）

### ⚠️ startAndExecute 的"陷阱"

`startAndExecute` 的语义是 **"启动 + 跑第一步"**（AGENTS.md §5.4）：

- submitType=1 时，第一个 task（apply）会被**自动执行**
- startAndExecute 返回时，apply.state=DONE，**active task 已是 task1**
- 此时如果调用 `task.execute(operator=发起人)` 提交 task1，会报 `"operator user1 not allowed"`（task1 actor=leader 不含 user1）

### 实测序列

```python
# 错误做法
inst = startAndExecute(...)  # apply 自动完成，active=task1(actor=leader)
execute(operator=user1)       # ❌ "operator user1 not allowed"

# 正确做法
inst = startAndExecute(...)  # apply 自动完成，active=task1
execute(operator=leader)     # ✅ task1 完成
execute(operator=manager)    # ✅
execute(operator=boss)       # ✅
```
