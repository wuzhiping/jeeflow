## 4. 关键发现

1. **assignee=变量 key 替换**：vars_['deptLeader']='leader' → actor=leader
2. **多 actor 逗号分隔 + performType=0**：单 task + actorIds=['userA','userB']（区别于会签多 task）
3. **is_allowed 检查**：operator in actorIds，userA 有效
4. **单 task + actorIds 列表**：userA 执行后 task.state=20 → 流转 end（无需 userB 执行）

### ⚠️ 文档 §71 新增

**performType=0 + 多 actor**：与 performType=1 + 单 actor 行为不一致：

| 配置 | 行为 |
|---|---|
| `performType=0` + `assignee=userA,userB` | 单 task，actorIds=[userA,userB]，任一执行即可 |
| `performType=1` + `countersignType=PARALLEL` + `assignee=userA,userB` | 多 task（每 actor 一行），全部完成流转 |
| `performType=1` + `assignee=userA` | 单 task，actorIds=[userA]，与 performType=0 单 actor 相同 |

## 5. 文档改进

`docs/known-issues.md §71`：performType=0 + 多 actor 是 OR 门控（任一执行即可流转），
不等同于 PARALLEL 会签的 AND 门控。
