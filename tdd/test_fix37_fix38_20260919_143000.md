### 1.1 §20 FIX-T37：SimpleExprEvaluator 用 ast 替换 regex

**改动文件**：`./main_common.py`（`SimpleExprEvaluator` 类）

**核心逻辑**：
```python
async def eval(self, expr: str, vars: dict):
    import ast, re
    if not expr or not expr.strip():
        return False
    # OGNL 风格预处理
    normalized = re.sub(r"#(\w+)", r"\1", expr)
    normalized = normalized.replace("||", " or ").replace("&&", " and ")
    normalized = re.sub(r"!(?!=)", "not ", normalized)
    try:
        tree = ast.parse(normalized, mode="eval")
    except SyntaxError:
        return False
    try:
        return self._eval_node(tree.body, vars)
    except (TypeError, ValueError, KeyError, AttributeError):
        return False
```

**支持语法**（AST 白名单）：
- `Constant`：int / float / str / True / False / None
- `Name`：变量查找（`var` / `#var` / `True` / `False` / `None`）
- `BinOp`：加减乘除模
- `UnaryOp`：`not` / `-x` / `+x`
- `BoolOp`：`and` / `or`（short-circuit）
- `Compare`：`==` / `!=` / `>` / `<` / `>=` / `<=`（链式）

**拒绝**（兜底返回 False）：
- `Call`（函数调用）
- `Attribute`（属性访问）
- `Subscript`（下标）
- 任何 import / 复合语句

### 1.2 §16 FIX-T38：custom handler registry

**改动文件**：
- `./vendor/jeeflow/extensions.py`：新增 `custom_handler_registry: dict[str, Callable]`
- `./vendor/jeeflow/engine.py`：`_execute_node` 拆出 `_execute_custom_node` 分支
- `./main_common.py`：新增 `build_custom_handlers()` 注册示例 handler

**核心逻辑**：
```python
async def _execute_custom_node(self, node, inst, operator, vars_, flow):
    handler_key = node.properties.get("clazz", "")
    if not handler_key:
        raise ValueError(f"custom 节点[{node.id}]缺少 properties.clazz")
    if not self.ext.custom_handler_registry:
        raise ValueError(f"custom 节点[{node.id}] handler='{handler_key}' 未注册")
    handler = self.ext.custom_handler_registry.get(handler_key)
    if handler is None:
        raise ValueError(f"未注册，已注册: {list(self.ext.custom_handler_registry.keys())}")
    args = node.properties.get("args", "")
    result = handler(node, inst, vars_, args)
    if hasattr(result, "__await__"): result = await result
    val_key = node.properties.get("val", "")
    if val_key and result is not None:
        vars_[val_key] = result
    if flow is None:
        from .model import parse_flow_model
        def_ = await self.repo.find_define_by_id(inst.defineId)
        if def_: flow = parse_flow_model(json.loads(def_.content))
    if flow is None: return
    for n in _follow_edges(flow, node.id):
        await self._execute_node(flow, inst, n, operator, vars_)
```

**handler 签名**：`async def(node: FlowNode, inst: ProcessInstance, vars_: dict, args: str) -> Any`

**字段语义**（v1.9.0+）：
- `clazz`：必填，handler 注册 key
- `methodName`：冗余（Python callable 模式无 Java 反射概念）
- `args`：字符串参数（handler 自行解析）
- `val`：结果变量名（写入 `vars_[val]`）

## 3. 修复影响范围

| 场景 | v1.8.x 行为 | v1.9.0 行为 |
|------|-------------|-------------|
| decision expr `\|\|` / `&&` | regex 不匹配 → False → 兜底 | ast 正确求值 |
| custom 节点 clazz/methodName | 静默卡死（FIX-T17 改为 raise） | 调注册 handler，推进下游 |
| `#var` 风格（OGNL） | 通过（FIX-T3 regex 兼容） | 通过（预处理 `re.sub`） |
| 函数调用 / 属性 / 下标 | 报错 | 返回 False（白名单外兜底） |
| handler 未注册 | 流程卡死 | 抛 ValueError 立即报错 |
