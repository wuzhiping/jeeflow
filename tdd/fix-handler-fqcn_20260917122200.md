## 4. 修复（v1.5.2，FIX-T2）

T1+T2 暴露 `engine.py:443-446` handler 解析失败**完全静默**（无任何日志），TDD 只能通过 activeTaskList=[] 间接判断。

**修复**：`main.py` monkey-patch `_resolve_actors`，3 类失败各打 stderr warning：

```python
_orig_resolve_actors = engine._resolve_actors
async def _logged_resolve_actors(node, inst, operator, vars_):
    handler_name = node.properties.get("assignmentHandler", "")
    if handler_name and engine.ext and engine.ext.registry:
        h = engine.ext.registry.resolve_assignment(handler_name)
        if not h:
            print(f"[FIX-T2 WARN] handler not registered: FQCN='{handler_name}' node_id='{node.id}' (process={inst.defineId})", file=sys.stderr, flush=True)
            return []
    actors = await _orig_resolve_actors(node, inst, operator, vars_)
    if handler_name and not actors:
        print(f"[FIX-T2 WARN] handler '{handler_name}' returned empty actors for node_id='{node.id}' (process={inst.defineId}); check SPI role_code", file=sys.stderr, flush=True)
    return actors
engine._resolve_actors = _logged_resolve_actors
```
